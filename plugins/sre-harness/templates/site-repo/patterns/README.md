# Deployment patterns

One page per pattern: an agreed way a service is shipped at this site. The
file name without `.md` is the pattern id that catalog entries refer to.

Describe patterns as they are used, not as you wish they were. Each page
should say: when to use it, where its configuration lives, how a change
ships, how it is monitored, how to roll back, its known failure modes, and
what a catalog entry for it must contain.
